Walking Skeleton — Phase 1

Goal
- Deliver a minimal end-to-end flow that exercises signup, login, session restore, and a simple dependents list.

Minimum Deliverables
- Signup screen that creates a user and stores token
- Login screen that authenticates and stores token
- UserContext that provides auth state and restores token from AsyncStorage on boot
- Dependents list screen with add/delete actions (UI can be minimal)

Notes
- Keep UI minimal; prefer functionality over polish for the skeleton.
- Use mocked backend responses or a simple dev server if the real API is unavailable.
