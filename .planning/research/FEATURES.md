# Research: FEATURES

Date: [2026-05-14]

Table stakes for a parental dental tracking app
- Account management: signup/login, session persistence
- Child profiles: create, edit, multiple children support
- Dental event logging: record by tooth (erupção, queda, procedimentos)
- Timeline/history: chronological view per child
- Educational content: articles and guidance
- Alerts/notifications: reminders and out-of-range alerts

Differentiators (post-MVP)
- Predictive timelines with adjustable thresholds and clinician calibration
- Integration with clinics (export/import records)
- Multi-device family sync and clinician access

Anti-features (avoid in v1)
- Real-time chat with professionals
- Complex billing or in-app purchases
